# Telegram-модуль UNICA & FLOWERS

Практическая часть курсовой работы «Создание интернет-магазина с Telegram-ботом с помощью нейросетей».

[Описание курсовой](../README.md) · [Пояснительная записка](../docs/COURSEWORK.md) · [Общая серверная часть](../sites/unika-flowers/README.md)

## Назначение

Модуль объединяет Telegram-бота и Mini App. Бот открывает магазин, доставляет уведомления сотрудникам, принимает сообщения покупателей и позволяет изменять статусы заявок. Mini App использует тот же интерфейс магазина, что и обычный браузер.

- [Открыть бота](https://t.me/Unika_Flowers_bot).
- [Открыть магазин](https://app8754275738.tgcloud.ai/).

Новые заказы хранятся в общей базе сайта. Обработчик `siteBridge` передаёт подтверждённую Telegram-платформой личность и роли серверу магазина. Модуль также содержит обработчики существующих заказов самого бота, необходимые для его текущей работы. Прежний веб-интерфейс в репозиторий не включён.

## Структура

| Каталог / файл | Назначение |
| --- | --- |
| `tgcloud/handlers/message.js` | Команды и входящие сообщения |
| `tgcloud/handlers/callback_query.js` | Нажатия кнопок Telegram |
| `tgcloud/endpoints/siteBridge.js` | Соединение Mini App с общей серверной частью |
| `tgcloud/lib/` | Навигация, роли, заказы, уведомления и диалоги |
| `tgcloud/schema.js` | Схема данных Telegram-модуля |
| `web/` | Актуальная статика Mini App |
| `scripts/` | Тесты и инструменты сопровождения |

## Команды бота

| Команда | Назначение |
| --- | --- |
| `/start` | Главное меню |
| `/catalog` | Переход к магазину |
| `/order` | Меню оформления заявки |
| `/orders` | Просмотр заказов |
| `/support` | Обращение в магазин |
| `/inbox` | Диалоги покупателей для сотрудников |
| `/cancel` | Отмена текущего ввода |
| `/id` | Telegram ID пользователя |
| `/help` | Справка |
| `/admin` | Панель сотрудников |

Права администратора и владельца проверяются на сервере. Отображение кнопки само по себе не предоставляет доступ к операции.

## Проверка

Требуется Node.js 22.15 или новее. Из этой папки:

```powershell
node --experimental-vm-modules --test scripts/*.test.mjs
```

Набор включает 34 теста: проверку ролей, изоляции данных, повторных запросов, работы каталога, статусов, сообщений и соединения с общей базой сайта. Тестовый SDK сохраняет отправку сообщений в памяти и не обращается к покупателям.

Для установки CLI и запуска вспомогательных инструментов:

```powershell
npm ci
```

Для временного стенда обработчиков бота:

```powershell
node --experimental-vm-modules scripts/qa-server.mjs
```

Адрес стенда: [http://127.0.0.1:4175/?role=owner](http://127.0.0.1:4175/?role=owner). Доступны роли `owner`, `admin`, `buyer`. Стенд использует временную базу и имитацию Telegram. Он предназначен для проверки обработчиков; полная демонстрация текущего магазина запускается по [инструкции веб-приложения](../sites/unika-flowers/README.md).

## Развёртывание

Облачная публикация требует собственного подключения Telegram Serverless и настройки параметров окружения. Учётные данные CLI в репозиторий не входят.

После настройки подключения:

```powershell
npm run check
npm run deploy
```

Изменения схемы базы требуют отдельной проверки и применения миграций средствами CLI. Для публикации на другом боте также необходимо настроить его адрес Mini App и идентификаторы сотрудников. Подробности текущей архитектуры приведены в пояснительной записке.
