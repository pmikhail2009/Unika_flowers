# UNICA & FLOWERS

## Курсовая работа

**Тема:** «Создание интернет-магазина с Telegram-ботом с помощью нейросетей».

**Учебное заведение:** Лицей РАНХиГС

**Курс:** «Нейросети для жизни и учёбы»

**Автор:** Писенко Михаил

**Класс:** 11-3

**Год:** 2026

Проект автоматизирует выбор товаров, приём заявок и взаимодействие покупателей с сотрудниками магазина гортензий. Система доступна в обычном браузере и в Telegram Mini App; бот доставляет уведомления и позволяет обрабатывать обращения.

[Открыть магазин](https://app8754275738.tgcloud.ai/) · [Telegram-бот](https://t.me/Unika_Flowers_bot) · [Пояснительная записка](docs/COURSEWORK.md)

### Цель и задачи

Цель работы — создать с помощью нейросетей работающий проект для реального применения и получить доход от его разработки или сопровождения. Практический результат — магазин, объединяющий каталог товаров, оформление заявок и управление заказами.

Для достижения цели решены следующие задачи:

1. Определены роли пользователей и требования к системе.
2. Спроектированы клиентская и серверная части, структура базы данных.
3. Реализованы каталог, поиск, фильтры, сравнение товаров и корзина.
4. Разработаны оформление заявок, история заказов и переписка с магазином.
5. Созданы панель сотрудников и интеграция с Telegram.
6. Выполнено автоматизированное тестирование серверной логики.

### Функциональные возможности

| Пользователь | Возможности |
| --- | --- |
| Покупатель | Просмотр каталога, поиск и сравнение сортов, корзина, оформление и отслеживание заявки, переписка |
| Администратор | Обработка заказов, ответы покупателям, изменение каталога, просмотр журнала действий |
| Владелец | Возможности администратора, управление сотрудниками и их доступом |

Заявка проходит статусы от нового обращения до завершения или отмены. Повторная отправка одного запроса не создаёт второй заказ. Стоимость и условия получения подтверждает магазин; онлайн-оплата в проект не входит.

### Использование нейросетей

В работе нейросеть выступает помощником при формулировании требований, создании интерфейса и программного кода, подготовке тестов и документации. Результаты её работы проверяются чтением кода, запуском приложения и автоматическими тестами. Ответственность за итоговое решение и его демонстрацию несёт автор проекта.

### План получения дохода

Проект можно предложить небольшому магазину как услугу разработки и настройки, а затем отдельно оказывать сопровождение: обновление каталога, изменение интерфейса и поддержку бота. Для защиты работы важно показать готовый продукт, объяснить его пользу заказчику и отделить планируемый доход от уже полученной оплаты.

### Архитектура и технологии

Веб-интерфейс обращается к общей серверной логике по HTTP API. Telegram Serverless проверяет личность пользователя Mini App и передаёт запросы серверу магазина. Новые заказы обоих каналов хранятся в общей базе.

| Часть системы | Технологии |
| --- | --- |
| Интерфейс магазина | HTML, CSS, JavaScript, Telegram Web App SDK |
| Сервер сайта | JavaScript, HTTP API, маршрут Next.js |
| Хранение данных | SQLite / Cloudflare D1, Drizzle ORM, SQL-миграции |
| Telegram-бот | Telegram Serverless, JavaScript |
| Локальный запуск и тесты | Node.js 22.15+, встроенный тестовый модуль Node.js |

### Запуск для демонстрации

Установите **Node.js 22.15 или новее**, откройте терминал в корне репозитория и выполните:

```powershell
cd sites/unika-flowers
node scripts/local-server.mjs
```

Откройте [локальный магазин](http://localhost:4180/). Для этого режима установка npm-зависимостей не требуется. Локальная база создаётся автоматически; данные первого входа сотрудника сохраняются на компьютере в `.local/access.txt`.

Подробнее: [веб-приложение](sites/unika-flowers/README.md), [Telegram-модуль](UNIKAFLOWERS_V2/README.md).

### Тестирование

Из корня репозитория:

```powershell
cd sites/unika-flowers
node --test scripts/shop.test.mjs scripts/telegram.test.mjs

cd ../../UNIKAFLOWERS_V2
node --experimental-vm-modules --test scripts/*.test.mjs
```

На 21 октября 2026 года пройдены **59 тестов**: 25 для общей серверной части и 34 для Telegram-модуля. Проверены права доступа, обработка заявок, защита от повторных запросов, переписка, уведомления и изменения статусов. Тесты используют изолированные данные.
