# UNICA & FLOWERS

Актуальные исходники магазина и Telegram-бота на 21 октября 2026 года.

- [Сайт и общая серверная часть](sites/unika-flowers/README.md): каталог, заказы, переписка, сервер Sites/D1, миграции и тесты.
- [Telegram-бот и Mini App](UNIKAFLOWERS_V2/README.md): Telegram Serverless, обработчики, права и текущая статика.

Структура рабочих папок сохранена для относительных ссылок между проектами. Прежний UNIKABOT, прежний интерфейс web/legacy, промежуточные шаблоны, резервные копии и история старых репозиториев не включены. Ссылки на прежние заказы в документации описывают существующее развёртывание; код прежнего интерфейса намеренно отсутствует в этом репозитории.

## Локальная работа

Для сайта: Node.js >=22.13, затем в sites/unika-flowers выполните npm ci, npm test и npm run dev:standalone. Для Telegram-проекта: в UNIKAFLOWERS_V2 выполните npm ci и npm run check. Настройка публикации описана в README каждого проекта.

## Секреты

API-ключи, TELEGRAM_BOT_TOKEN, TELEGRAM_BRIDGE_SECRET, пароли и учётные данные публикации задаются отдельно через секреты хостинга или локальное окружение. Рабочие значения, локальные базы, заказы покупателей, .tgcloud и .env в репозиторий не включаются. Примеры и фикстуры тестов используют только тестовые значения.
