# Веб-приложение UNICA & FLOWERS

Практическая часть курсовой работы «Создание интернет-магазина с Telegram-ботом с помощью нейросетей».

[Описание курсовой](../../README.md) · [Пояснительная записка](../../docs/COURSEWORK.md) · [Техническое задание](BRIEF.md)

## Назначение

Веб-приложение предоставляет каталог гортензий, корзину, оформление заявок, историю заказов и переписку. Сотрудники управляют товарами и обрабатывают заявки в административной панели. Сайт и Telegram Mini App используют общую серверную часть для новых заказов.

## Основные модули

| Каталог / файл | Назначение |
| --- | --- |
| `public/` | HTML, CSS, JavaScript, фотографии и начальный каталог |
| `server/shop.mjs` | Операции каталога, заказов, сотрудников, авторизации и переписки |
| `server/telegram.mjs` | Очередь уведомлений и обработка действий из Telegram |
| `server/validation.js` | Проверка входных данных и переходов статусов |
| `server/sqlite.mjs` | Локальный адаптер SQLite |
| `app/api/[action]/route.ts` | HTTP-маршрут облачного приложения |
| `db/schema.ts` | Описание структуры базы данных |
| `drizzle/` | Версионируемые SQL-миграции |
| `scripts/local-server.mjs` | Локальный сервер для демонстрации |

## Локальный запуск

Требуется Node.js 22.15 или новее. Выполните в этой папке:

```powershell
node scripts/local-server.mjs
```

Адрес: [http://localhost:4180/](http://localhost:4180/).

Локальный сервер использует SQLite и встроенные средства Node.js, поэтому для демонстрации не требуется `npm install`. При первом запуске создаются база `.local/shop.sqlite` и учётная запись `owner` со случайным паролем. Данные входа находятся в `.local/access.txt`. Папка `.local/` исключена из Git. Для остановки сервера нажмите Ctrl+C.

Локальный режим позволяет проверить каталог, оформление заказов, панель сотрудников и переписку. Доставка реальных Telegram-уведомлений требует отдельной настройки облачной интеграции.

## Проверка

```powershell
node --test scripts/shop.test.mjs scripts/telegram.test.mjs
```

Набор включает 25 тестов. Проверяются доступ к заказам, валидация, повторные и одновременные запросы, статусы, переписка, роли сотрудников, сеансы и очередь Telegram-уведомлений. Используется SQLite в памяти; рабочие заказы не изменяются.

## Облачная сборка

Для сборки приложения с npm-зависимостями:

```powershell
npm ci
npm run build
```

Облачный вариант использует Sites и D1 с привязкой `DB`. Параметры интеграции задаются в окружении хостинга. Для работы с другим развёртыванием необходимо согласованно настроить адреса сайта и Telegram-модуля.

Сначала публикуется сервер сайта, затем актуальное содержимое `public/` переносится в `../../UNIKAFLOWERS_V2/web/` и публикуется Telegram-проект. Рабочие значения параметров доступа отсутствуют в исходниках.

## Ограничения

Проект принимает заявки; оплату и условия получения подтверждает продавец. Автоматического резервирования остатков нет. Повторная доставка уведомлений выполняется при последующих обращениях к системе; отдельный фоновый планировщик не настроен.
